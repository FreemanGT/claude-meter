§05 — PRIVACYTHE APP: 3 HOSTS · 0 ANALYTICS

Reads. Never writes. Reads. Never writes.

Claude Meter uses the sign‑in Claude Code already saved on your Mac. It reads it from the macOS Keychain, through Apple’s own security tool, or from ~/.claude/.credentials.json, and never changes it. Short‑lived tokens are refreshed in memory, never written back.

0%Is it actually free?

Yes, and open source (MIT). No trial, no account, no paid tier. The download asks for your email, used only for Claude Meter updates. You do need Claude Pro or Max, since that’s what it measures.

10%Is it open source?

Yes. The whole app is MIT‑licensed and on GitHub, so you can read exactly what it does with your sign‑in, build it yourself, or send a fix. If it earns its spot in your notch, a star helps other people find it.

Star it on GitHub

20%What do I need?

A Mac on macOS 14.4 or later (Apple Silicon or Intel) and Claude Code signed in with a Claude Pro or Max plan, even if you mostly use claude.ai: install Claude Code, then run claude and type /login with your Pro or Max account. API‑key (Console) logins and a custom CLAUDE_CONFIG_DIR aren’t supported.

It’s signed with an Apple Developer ID and notarized by Apple, so macOS opens it without a fight.

30%Is there a Windows version?

Not yet. Join the waitlist for one email when Windows ships. Nothing else.

40%Will macOS ask for my keychain password?

Usually not. Claude Meter reads the sign‑in Claude Code already saved (the macOS Keychain first, then ~/.claude/.credentials.json). When it renews an expired sign‑in, it saves the new one back there the way Claude Code does, so the claude in your Terminal stays signed in. If a prompt asks to let “security” use “Claude Code-credentials”, that’s Apple’s own keychain tool fetching it for Claude Meter. Enter your Mac password and choose Always Allow.

50%Who does it talk to?

Three places: api.anthropic.com for your usage, every 5 minutes and when you hover, but never more than once every 3 minutes; platform.claude.com to refresh a token; and claudemeter.vercel.app/version.json once a day. If there’s a newer version, the right‑click menu shows “Update available”, which brings you back here to download it. The app has no analytics, no account, no server of ours.

60%Will it nag me?

Only if you ask it to. Notifications are off until you turn them on. Then you get a heads‑up at 50, 80 and 95% of a session, at 80 and 95% of weekly and per‑model limits, and a “back to full” when a tight window resets.

70%What if my Mac has no notch?

You get a compact pill at the top centre instead. That covers Macs without a notch and a MacBook running lid‑closed on an external display. With the lid open, the island stays on the built‑in screen, so switch on Menu bar item to keep your numbers in the menu bar. It steps aside in full‑screen apps.

80%How do I quit it, or change settings?

There’s no Dock icon, so right‑click the island, or click the menu bar item if you’ve turned it on. Appearance, which limits show (session, weekly, the model limit, any mix), percentages, burn‑rate estimates, notifications, the menu bar item, launch at login and Quit all live there. To uninstall, quit it and drag it from Applications to the Trash.

90%Is this made by Anthropic?

No. It’s an independent project by Yiftach Freeman, not affiliated with or endorsed by Anthropic.

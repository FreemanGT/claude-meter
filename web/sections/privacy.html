Claude Meter uses the sign‑in Claude Code already saved on your Mac. It reads it from the macOS Keychain, through Apple’s own security tool, or from ~/.claude/.credentials.json, and never changes it. Short‑lived tokens are refreshed in memory, never written back.

The Mac download asks for your email; the Windows waitlist asks for your name too. Both go to the maker’s Google Sheet with your OS and the page that sent you here, never shared or sold. A Mac email only ever gets Claude Meter updates; the waitlist gets one email when Windows ships, nothing else. Your browser remembers the email so you don’t retype it, and asks GitHub for the star count every few hours at most.

Works with Claude Pro and Max sign‑ins from Claude Code. API‑key (Console) logins and a custom CLAUDE_CONFIG_DIR aren’t supported.
